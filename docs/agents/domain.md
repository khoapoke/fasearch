# Domain documentation for agents

This repository has one shared domain glossary at `CONTEXT.md`. Read it before naming actors, Product Versions, Product Images, sessions or publications. Read relevant ADRs under `docs/adr/` before altering their decisions.

Authority for project scope is the official proposal, then `docs/10_DECISION_REGISTER.md` and schemas/contracts, then the research protocol and blueprint/playbooks. Task packets are execution records, not a competing specification. If a ticket conflicts with an authority, flag the conflict in the packet and pause the affected change for the project representative.
