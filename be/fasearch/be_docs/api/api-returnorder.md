# TÀI LIỆU API: MODULE RETURN ORDER (ĐỔI / TRẢ HÀNG)

Module `returnorder` (FR-48 → FR-51: tra cứu hóa đơn đổi trả, kiểm tra điều kiện, lập phiếu đổi / trả, nhập kho hàng thu hồi) **chưa có controller nào trong source**, nên hiện chưa có endpoint để đặc tả. Trạng thái từng chức năng xem [module.md](../module.md) (mục 10); đặc tả endpoint sẽ được bổ sung khi module được triển khai.
